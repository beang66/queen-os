# Queen-OS 견적 발행 안전성 검증 및 개선 기록

- 점검일: 2026-11-17
- 대상: `beang66/queen-os` / `main` `1fcc9ae34a90b93c4c721cde091363967f7da9c3` 기준
- 수행 방식: AJB PC 임시 복사본 + **폐기 가능한 로컬 PostgreSQL 컨테이너**, 실제 사업장/개인정보/운영 DB 사용 없음
- 목적: **고객 주문 입력 → 검수 → 서버 재계산 → 발행 → Excel 내보내기** 과정의 계산 신뢰성과 정보 노출 위험 감소

## 발견된 결함(수정 전 실측)

1. `POST /api/quotes`가 클라이언트 계산 결과를 그대로 저장. 최종 총액을 **1원으로 변조**하고 검수 결과 `ERROR`를 넣어도 HTTP 200으로 발행 및 DB 저장됨.
2. `prisma/migrations/20260910030636_init/migration.sql`의 선행 UTF-8 BOM 때문에 빈 PostgreSQL의 `prisma migrate deploy`가 `P3018 / syntax error near BOM`로 중단됨.
3. 단일 Excel 생성 로직에서 제조원가·마진율·공급가액을 함께 출력. 별도 고객용 안전 표식과 권한에 따른 출력 범위가 없었음.
4. 이전 Excel 엔드포인트가 사용자 제출 견적 JSON을 그대로 파일에 반영함. 서버가 저장한 문서의 사실성 확인이 없었음.

## 구현한 수정

### 서버 견적 발행 게이트

- 요청을 받은 순간 서버가 DB 단가표로 견적을 **다시 계산**합니다.
- 서버의 계산 명세·총액·단가 스냅샷과 사용자가 검토한 결과가 다르면 `409`로 발행을 차단합니다.
- 서버 검수에서 `ERROR`가 발생하거나 전송된 검수 결과에 `ERROR`가 있으면 발행을 차단합니다.
- 단가표에 없는 임시 기본단가 `temp-*`가 포함되면 발행을 차단합니다.
- 숨김 품목이 있으면 실제 청구 총액과 화면 표시의 불일치 위험이 있어, 적절한 재계산 로직이 구현될 때까지 **발행을 보류**합니다.
- 수용한 견적은 클라이언트 복사본이 아니라 **서버 재계산 결과**를 DB에 저장합니다.
- 목표 마진율 필드를 0~100 범위로 제한합니다.

### Excel 출력 구분

- `POST /api/quotes/excel`와 기존 `POST /api/export/quote-excel`을 동일한 검증 로직으로 통일.
- 본문은 `{ "quoteId": "...", "audience": "customer" | "internal" }`만 허용; 서버가 저장한 견적을 직접 불러옵니다.
- 고객용은 판매단가/공급가액/VAT/총액만 출력하며 **원가·마진·원가단가표는 포함하지 않습니다**.
- 고객용 파일 상단에는 **검증용 · 대외 발송 금지**를 표시합니다. 실제 사업자 정보는 현재 예시 자료이며 정식 견적서로 배포해서는 안 됩니다.
- 내부용 출력은 `ADMIN`/`ESTIMATOR`만 허용합니다. 기존 조회전용 `VIEWER`는 POST 요청을 차단하는 정책을 두 URL 모두에서 일치시켰습니다.
- 사용자 문자열에 대한 스프레드시트 수식 주입 방어 및 파일명 정제, 응답 캐시 금지를 적용했습니다.

### DB 마이그레이션

- 첫 마이그레이션 SQL 앞의 UTF-8 BOM만 제거. SQL 내용 자체는 변경하지 않았습니다.

## 독립 재현 가이드

**반드시** 별도의 PostgreSQL 테스트 DB에서만 실행합니다. 기존 운영 `DATABASE_URL`, `DIRECT_URL`을 재사용하지 마세요. 테스트는 테이블/계정/견적 레코드를 생성합니다.

```powershell
docker run -d --rm --name queen-os-audit-20261117 `
  -e POSTGRES_USER=queen_test -e POSTGRES_PASSWORD=queen_test_pw `
  -e POSTGRES_DB=queen_os_ponytail_20261116 `
  -p 127.0.0.1:55437:5432 postgres:15-alpine

$env:DATABASE_URL = 'postgresql://queen_test:queen_test_pw@127.0.0.1:55437/queen_os_ponytail_20261116?schema=public'
$env:DIRECT_URL = $env:DATABASE_URL
$env:QUEEN_OS_TEST_DATABASE_URL = $env:DATABASE_URL
npm ci
npm run db:migrate:deploy
npm test
npm run build
npx tsc --noEmit
npm run test:quote-safety:e2e
docker stop queen-os-audit-20261117
```

검증 스크립트는 `127.0.0.1:55437/queen_os_ponytail_20261116` 문자열이 포함된 DB URL이 아니면 즉시 중단하도록 설계했습니다. 테스트는 앱을 로컬 임시 포트에 띄우며 `DEMO_AUTO_LOGIN`을 격리 환경에서만 사용합니다.

## 아직 해결되지 않은 현업 도입 조건

1. **기획/화면상의 목표 마진율·할인·추가금·품목 숨김과 서버에 발행되는 금액**이 사용자 기대대로 일치하는지 완전 검증하지 않았습니다. 특히 품목 숨김은 안전상 현재 발행 차단.
2. 고객용 Excel에는 법적 거래정보가 아닌 **가상 사업자 정보를 기반으로 한 미리보기**만 제공됩니다. 정식 고객 견적서로 사용하지 말 것.
3. Gemini의 실제 입력 추출 품질·도면 인식 품질, 다중 사용자 운영, 권한별 UX 및 지속 운영 환경은 추가 검증이 필요합니다.
4. 변경 전 이미 발행된 기존 견적서의 데이터 정합성은 자동으로 소급 교정되지 않습니다.
5. 실제 실무자의 주문서와 업무시간을 사용한 효과 측정, 재사용 의사, 고객 유료 전환 근거는 **아직 없음**.
